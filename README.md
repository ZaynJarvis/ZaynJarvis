# Zayn Jarvis

I build tools for AI agents that need **context**, **coordination**, and **evidence** —
and the occasional thing that's just fun, like turning a Mac trackpad into a drawing
instrument.

**[zaynjarvis.com](https://zaynjarvis.com)** — the full field index, with source and
project status kept visible.

## Current focus

**[OpenViking](https://github.com/volcengine/OpenViking)** — open-source context
database for AI agents: memory, resources, skills, and provenance behind a
`viking://` filesystem. Upstream project by the Volcengine team; I contribute there.
